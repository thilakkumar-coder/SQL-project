# 🗄️ SQL Normalization and Joins Project

## 📌 Overview

This project focuses on **SQL database normalization and table joins** to organize relational data efficiently and retrieve meaningful information from multiple tables. The project demonstrates practical SQL concepts used in database design and data analysis.

## 🧩 Normalization

The database is organized using normalization principles:

### 1NF – First Normal Form

* Removes repeating groups.
* Ensures each column contains atomic values.

### 2NF – Second Normal Form

* Achieves 1NF.
* Removes partial dependency on composite keys.

### 3NF – Third Normal Form

* Achieves 2NF.
* Removes transitive dependencies.
* Ensures non-key attributes depend only on the primary key.

## 🔗 SQL Joins

The project demonstrates different types of SQL joins:

* **INNER JOIN** – Retrieves matching records from both tables.
* **LEFT JOIN** – Returns all records from the left table and matching records from the right table.
* **RIGHT JOIN** – Returns all records from the right table and matching records from the left table.
* **FULL JOIN** – Retrieves matching and non-matching records from both tables.
* **SELF JOIN** – Joins a table with itself when required.
